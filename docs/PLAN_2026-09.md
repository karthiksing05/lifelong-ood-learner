# Re-workshopping lifelong-ood-learner: from "address a class table" to "compose prototypes and fold new ones into the manifold"

Plan written 2026-09-25 from: the September review and code audit of the repo, Zekun's ICLR 2027 submission, the
group's ACS 2026 Cobweb-diffusion paper, the Cobweb sources on disk, a ~200-fetch literature sweep, and three design
passes (mechanism, benchmark, restructure). Sections 1-8 are the plan; Appendix A is the evidence base.

## Context

`lifelong-ood-learner` is the primary repo for the lifelong/OOD thesis. Its current architecture is the three-tier ladder
ADDRESS (72 B point in a linear factor basis over the class-embedding table) / EXTEND (1 KB new basis direction) /
BLOCK (a value-gated rank-1 LoRA, 276 KB on ColorMNIST, 1.2 MB on Shapes3D), with a Cobweb-flavoured
create/merge router over *factor hypotheses* (C5). The September review (`docs/REVIEW_2026-09.md`) retracted the
earlier headlines and left two honest findings: (i) a per-VALUE gated adapter is the only thing that renders a
genuinely new value while preserving old classes exactly; (ii) parameter sparsity is not functional sparsity, the
gate/anchor is what preserves.

The user's new direction: lifelong OOD learning **is** composing seen prototypes, and knowledge of *how* prototypes
compose is what lets a new OOD instance be added cheaply and folded into the existing manifold. Zekun Wang et al.'s
ICLR 2027 submission (`_ICLR_2027__Diffusion_Composition_Generalization.pdf`, "Test-time compositional generalization
in diffusion models via prototype discovery") supplies the prototype notion this thesis needs (a prototype is a mode
of a noisy marginal p_t, reached by score ascent; the noise level sets its abstraction level; a datum induces a
hierarchy of distinct prototypes; held-out compositions are generated from a product of selected prototypes) and
names exactly our gap as its limitation: *"A full mechanism for detecting, consolidating, and reusing genuinely new
primitives remains future work."* Our paper is that mechanism, told as lifelong learning. Target venue: ICML 2027
(the pasted notes). Image continual-learning benchmarks first; diffusion policies (LIBERO) later.

## 1. Cynical audit of what is there (what to drop, what to keep)

### 1a. The address/extend/basis idea does not implement the thesis

| what the repo does | why it is not "composing seen prototypes" |
|---|---|
| ADDRESS = `c_new = mu + sum_f g_f (w_f . V_f)` in the class-embedding table (`lifelong_ood/compose.py`, `neural/idealwords.py`) | The "prototypes" are supervised factor VALUES recovered by a post-hoc linear regression over a class table that was trained with slot labels. On an unconditional or pretrained backbone there is no basis and the tier does not exist (`docs/THEORY.md` §1 admits ADDRESS needs a table with several times more rows than factor values). Nothing about the generator's own density is composed. |
| EXTEND = one new 256-float direction | Renders a genuinely new value at 0.000 on both datasets (review Part 3a/3b). The tier is dead. |
| BLOCK = `KeyedLoRA` per value, gated by a label coordinate | The only working mechanism, but the gate is the *label* ("value present in the coordinates"). Label-free gating does not exist. 276 KB to 1.2 MB per value is not "minimal", and consolidation into the weights pays the drift it saves (17% eps-drift ColorMNIST, -0.12 old classes Shapes3D). |
| Router = C5 create/merge over "which FACTOR is new" hypotheses | Cobweb's operators are being used as bookkeeping over a supervised factor space. Proposition 7 (attribution needs a second concept) is real but is a statement about *additive label conditioning*, not about prototypes. |
| Flagship C3: 0.980 from a 1-image read | Measures that 72 B of coordinates reach combinations a backbone pretrained on all 480k Shapes3D images can already draw. Addressing, not learning. |
| Zekun's discovery machinery (`neural/composable.py`, `poe-guided`) | Used only as a *baseline* that loses on recall; its prototype discovery (the part that makes prototypes label-free) was never put in the lifelong loop. |

Further faults the code-level audit (2026-09-25) adds to the review's own list:

- **The "value node" is the old BLOCK.** `inject_gated_lora` puts rank 1 on every Conv/Linear
  (`lifelong_ood/neural/cobweb_update.py:284`): 68,894 params = 275,576 B, about 1% of the 6.8M UNet, switched on
  by a label. The ladder is really 0 B / 72 B / 277 KB-1.2 MB.
- **Uncharged state.** Every stored concept keeps 8 self-generated samples plus a `copy.deepcopy(model)` teacher, a
  full copy of the backbone (`experiments/c5_router_cobweb.py:350-364`, `c1_cobweb_update.py:628-638`).
- **"Old classes exact" is by construction**: old classes are sampled with no adapter on (c5 `:580-584`).
- **One new value, ever**, always on the same factor, in a 20-concept stream; "3/3 right merges" is three decisions;
  the final configuration was chosen by iterating tags CW -> ... -> FINAL2 on the same seeds 0-2, no held-out stream.
  No new-FACTOR population exists, so the BLOCK tier was never tested.
- **Reads enumerate the full Cartesian product of factor values** (c5 `:380`); cost is exponential in factors.
- `THE_TASK.md` says one example per concept; C5 feeds 64 (48 on Shapes3D). On Shapes3D the adapter always hit the
  800-step cap, so the absorption criterion was never met.
- **Anchoring is generative self-distillation** (LwF / pseudo-rehearsal); the n-series already had a `gen-distill`
  baseline. It is a real finding about *what* preserves, not a new method.
- ColorMNIST checkpoints still run the permuted pixel layout; c-series coverage is pixel-space (recall 0.000 where
  Inception space gives 0.180); ten diverging sampler entry points; `results/*.json` is gitignored so the review's
  numbers are not under version control; `main` is 72 commits ahead of an unreachable origin.
- Accretion: 275 Python files / 51.6k lines (122 experiment scripts: 85 n-, 5 e-, 5 c-series; 96 `diag_*`), 20 docs /
  11.8k lines (RESULTS.md alone 6.5k), 798 result files / 11 GB, 53 sbatch files, 349 commits. Every front-page doc
  (README, CONTRIBUTIONS, SCOREBOARD, FINAL_REPORT, THE_TASK, VLA_PATH, OUTLINE) describes the pre-September stack.
- Zekun's composition operator (`lifelong_ood/compose.py`: mode ascent, submodular selection, PoE teacher) is used
  only by n2/n7/n9 and the e-series, never by the flagship, the storage loops or any c-series script.

Net: the current repo solves "cheap addressing of what a supervised class-conditional generator already renders, with
parameter isolation as the fallback for new content". That is a parameter-efficiency result, not a theory of
composition, and it cannot move to a pretrained/unconditional backbone or to a policy whose conditioning is not a
factored label table.

### 1b. What survives and must be kept

1. **Propositions 1-4 (`docs/COBWEB_UPDATE.md`)**: the ideal denoiser's one-instance update IS Cobweb's incremental
   update with soft responsibility r(x_t); noise level = tree depth (root at high noise, leaves at low noise);
   interference bounded by responsibility. This is the bridge between Cobweb and Zekun's prototype hierarchy and it
   becomes the theory spine of the new paper. `tests/test_cobweb_correspondence.py` checks it numerically.
2. **Functional sparsity, not parameter sparsity** (C1 frontier): a gated update is exact; a top-1% g^2/F mask
   without anchoring drifts ~500%; anchoring on the model's own samples is what preserves. The new design makes the
   gate label-free (responsibility from the prototype tree) instead of dropping it.
3. **Read at high noise** (read band u = 0.8-0.95): the conditioning carries the prediction only where the input's
   pixels do not; misreads come from pooling raw eps-losses dominated by low noise. This generalises to "decide
   membership at the level where the prototype is distinct".
4. **Proposition 7 in its label-free form**: from ONE instance you cannot tell at which level/branch a new mode
   attaches; a second instance sharing it can. Cobweb's create-then-merge is the answer; keep it, re-derived over
   prototypes rather than factors.
5. **Infrastructure** (full inventory in Appendix A5): the ColorMNIST `nobg3` and Shapes3D grey-wall benches
   (`experiments/c_bench.py`, `data/novel_value.py`), the Shapes3D `rows="correct"` loader fix, `KeyedLoRA` and
   `anchor_loss` and `ddim_sample` in `neural/cobweb_update.py`, Zekun's operator in `lifelong_ood/compose.py`,
   `evals.density_coverage` (switched to Inception space), `instrument.py`'s ceilings and Wilson resolution,
   `slurm/jobs/c_gpu.sbatch` (requeue + GPU-less resubmission), and the tests that pin exactness and the propositions.

## 2. The new architecture: PROTOTYPE COMPOSITION WITH FOLDING

**Representation.** A pretrained diffusion model (the inherited prior) plus a *prototype tree* T built over the
model's own score field: nodes are modes of p_t at noise levels (Zekun's discovery), depth = noise level
(Proposition 3), each node carrying Cobweb statistics (count, mode, diagonal extent) and, only when needed, a tiny
gated expert. Membership of an input x_t in a node is its responsibility r(x_t, t), computed from the node's local
Gaussian against its siblings: this is Cobweb categorisation and it is label-free.

**Three operators, each a Cobweb operator with a diffusion realisation.**

| Cobweb | here | cost |
|---|---|---|
| categorise / best-child | DECOMPOSE a query into the K prototypes (per level) that explain it, by Zekun's submodular selection on the tree instead of on a per-query pool | 0 weights; the code is K node ids + weights (tens of bytes) |
| add to node (incorporate) | ADDRESS: if the composition explains the query at the trained level in the read band, store the code, update node counts | 0 weights |
| create | FOLD a genuinely new prototype: a new node at the levels where the query is unexplained, realised in the weights by a responsibility-gated minimal expert trained with anchoring on the model's own samples of the sibling nodes (the r ~ 0 half of Proposition 2) | the expert; target: << the 276 KB LoRA (see Phase 2 frontier) |
| merge / promote | CONSOLIDATE: when a node has accrued enough instances (Cobweb's regime, MDL rule from RESULTS 6c-ter), distil its expert into the base weights under the same anchoring and delete the expert; merge nodes whose modes coincide at a level | net zero or negative memory |

**The claims this lets us make.**
- Compositionality is integral: a new instance that IS a composition costs nothing; storage grows with the vocabulary
  of prototypes, not with the stream (kept from the old thesis, now label-free).
- Hierarchy is integral: a new prototype only needs new nodes at the levels where it is distinct (Prop 3); coarse
  levels are inherited. Cost of folding tracks "depth of novelty", a new measurable quantity.
- Sparsity/symbol-likeness is necessary in FUNCTION space: the C1 frontier already shows that a dense or
  parameter-sparse edit destroys old prototypes; the discrete node gate (a symbol) is what makes the edit local.
- Finetuning a backbone = accumulating leaves under an inherited trunk (the evolutionary-prior story), with the
  consolidate operator as the "restructure" step that keeps the trunk global.

### 2b. The mechanism in detail (design 2026-09-25; everything below reuses named existing functions)

**Schedule caveat first.** `compose.PAPER_COLORMNIST` maps Zekun's linear-beta t/1000 onto this repo's cosine u.
Every level grid below is in this repo's u and must be calibrated here, never copied from the paper.

**Tree build (label-free, once per backbone, rebuilt after CONSOLIDATE).** Draw N0 = 512 unconditional samples
from the frozen base (`ddim_sample(model, 512, cls=None)`, null token). For each level in U = {0.10, 0.20, 0.30,
0.40, 0.55, 0.70} run `mode_ascent(samples, u, init="query", iters=150, lr=0.1, adam=True, tweedie=True)`
(`score.py:207`) so every chain starts at a noised MODEL sample (no query, no label); extents by `laplace_diag`
(4 probes); dedup by the per-dimension RMSE rule of `candidates_ascent` (`compose.py:149`, tol 0.05^2 D). The node
arrays are the `snap` dict that `candidates_tree` (`compose.py:26`) already consumes. Parent of node j at level l =
argmax over level-(l+1) nodes k of N(sqrt(a_{l+1}) m_j ; sqrt(a_{l+1}) m_k, a_{l+1} V_k + (1 - a_{l+1}) I): the ACS
paper's bottom-up agglomeration made explicit. Size control = Cobweb operators: per-level caps (32 fine / 16 mid /
8 coarse via `candidates_tree(per_depth_cap)`), MERGE two siblings when the parent Gaussian categorises both
children's own samples at >= 0.95 (no category-utility gain, `GaussianCobweb._cu`, `tree.py:64`), SPLIT only
where a coarse node's samples separate into >= 2 deduplicated modes.

**Node = (level u8, count f32, parent u16, expert u16, gain_accrued f32; mode as uint8 at the level's effective
bandwidth: 8x8x3 = 192 B for u >= 0.55, 16x16x3 = 768 B mid, 32x32x3 = 3072 B at u = 0.1; extent = 3 channel scalars
+ optional 32x32 support bitmask).** Fine ~3.2 KB, mid ~0.9 KB, coarse ~0.35 KB; a 150-node tree ~115 KB, shared
across the vocabulary and charged once. (Regeneration from (seed, level, index) = 8 B is possible but the regenerated
mode moves whenever the base moves, so charge the stored form.)

**DECOMPOSE with zero forward passes.** Modes and extents are in x0-space, so `loglik_perdim(x_q)` (`compose.py:159`)
against every node is ~200 x 3072 multiply-adds; then `submodular_select(L, K=3)` and `poe_teacher` give
(mu_T, Sigma_T); sampling = 50 DDIM steps x 2 forwards (CFG against `teacher_eps`), i.e. Zekun's sampling minus his
1920 chains x 150 iterations of discovery. Known risk (`compose.py:139-146`, RESULTS 5e-quater): query-initialised
chains dominate selection and the tree has none, so tree-only composition may lose on the 40 held-out slots;
fallback = "tree + local refinement" (8 chains x 50 iterations from the query at two levels, ~5 s). Phase 1 decides.

**Gate G1 (primary, analytic, label-free).** For node k at the grid level nearest t,
`r_k(x_t,t) = pi_k N(x_t; sqrt(a) m_k, a V_k + (1-a) I) / sum_{j in siblings(k)} pi_j N(x_t; ...)`, pi = count share;
this is `ScoreField._post` (`score.py:351`) restricted to one level's siblings, K_l x D FLOPs per (sample, step).
Above u = 0.7 only the root exists and r is the root share (Prop 3). At sampling the gate is either natural (a sample
wandering into the basin switches the expert on by itself: the manifold has grown, which the label-gated C1 LoRA
never did; free test: unconditional share of node k ~ count_k/N) or FORCED (r_k := 1) to generate from the node.
`KeyedLoRA.forward` needs one change: `state["on"]` becomes key -> weight so `out += w_k B_k(A_k(x))`.
**Gate G2 (control):** sigmoid((w_k . phi(x_t,t) - b_k)/tau) on the pooled `mida` output (129 floats = 516 B per
node), trained contrastively on the tree's own categorisation of the model's own samples; = MoRAM's content key;
expected weaker at mid noise.

**FOLD loss.** `L_fold = E_{x ~ query set, t} [ r_k ||eps_theta(x_t,t; w_k = r_k) - eps||^2 ] + lam E_{x ~ model's own
samples of ALL other nodes, t} [ ||eps_theta(x_t,t; w_k = r_k(x_t,t)) - eps_base||^2 ]`. The second term is
`anchor_loss` (`cobweb_update.py:201`) with the gate at its NATURAL value on old inputs; in C1 the LoRA arm's anchors
ran with the gate off, so its preservation was by construction and untested. lam = 10, batch 32 + anchor 32,
checks every 50 steps, cap 800.

**Stop rule (replaces the loss-based absorption rule).** Absorbed when (S1) generative membership: 32 samples from
the forced gate, noised to each level in the node's distinct band, are categorised to node k by G1 at >= the
calibrated old-node rate; (S2) no leakage: sibling nodes' own samples have mean r_k <= 0.05 and the gated function on
them differs from base by <= 2% eps-drift; (S3) coding gain of the gated model over the base on 16 held-back images
(`elbo_bits`, `router.py:667`, to be moved) >= the trained-node reference. Memorisation (`evals.memorization`) > 0.2
fails the arm regardless (Aparicio Rodriguez et al. 2026). Two reads stay distinct: membership at the levels where a
node is DISTINCT (predicted u in [0.15, 0.4] for backgrounds, calibrated label-free as the levels where old nodes'
own samples self-categorise >= 0.95) vs the conditional read band u = 0.8-0.95 (does the gated expert carry the
prediction where pixels cannot). Conflating them puts the membership read at the root where r is uninformative.

**What breaks if the tree is wrong.** Duplicate siblings split r to ~0.5 and the expert leaks onto the sibling's
samples (detect: mean r_k > 0.1 on sibling samples; the merge rule exists for this). A missing node attaches the fold
under a wrong parent (forced sampling still works; the natural gate misfires on old data). A wrong level puts the
expert on at high noise and drift appears at u >= 0.9 (C1's `anchor-full` seed 0 shows the fingerprint: 0.13-0.53 at
u = 0.95/0.99); report ABSOLUTE drift above u = 0.9 because the relative metric is ill-conditioned there.

**FOLD frontier (Q2), all arms at gate G1 + the anchored loss, on the C1 stream (4 tasks x 3 concepts x 64 images,
bg = 3 on `nobg3`); rank-1 counts are exact for `neural/unet.py` (base 64, mults (1,2,2), edim 256):**

| expert | bytes (ColorMNIST) | expected | kill |
|---|---|---|---|
| E0 ADDRESS only (tree PoE, no weights) | 0 | 0.000 on bg 3 (outside the hull, Zekun App. J) | control |
| E1 rank-1 `KeyedLoRA` all layers | 4 sum_l (in_l k_l^2 + out_l) = 275,576 | ~0.7 with the soft gate (0.716 label-gated) | taught < 0.5 or drift > 3% kills the GATE, not the expert |
| E2 rank-1 on the band chosen by responsibility-weighted gradient energy per block | res-32 band (stem, down0, downsample0, upsample, up0, out) 13,534 params = 54.1 KB; up0+out+stem 8,414 = 33.7 KB; res-16 98.8 KB; res-8 119.3 KB | colour lives at res-32: >= 0.9 x E1 at ~1/5 the bytes; a new shape needs res-8/16 | taught < 0.5 at every band <= 100 KB |

Per-concept memory for the paper: `bytes = 16 + mode_bytes(level) + 12 + [bytes(expert) if FOLD] + 2K (node ids and
weights for ADDRESS)`, reported next to its MDL crossover (`mdl_crossover_bits`, `router.py:732`, to be moved): at
the 6c-ter rate (~218 bits/image for a new primitive) E1 needs ~10^4 images to pay for itself and is never justified
by a 64-image concept; E3 at 5 KB needs ~190; a 1.3 KB FiLM ~50. The paper says so plainly.

**CONSOLIDATE (Q3).** Why C1's failed: it distilled into a top-5% mask (masks drift), its teacher covered only the
48 new-value samples while the unconditional field was anchored by 8 null-branch samples, and it ran a fixed 600
steps. Design: precompute targets into a transient fp16 table (n x n_t x 3072, ~12 MB for 512 x 8; charged as peak,
not stored; NO teacher copy), then
`L_cons = E_{node k's own gated samples} [ r_k ||eps_theta - eps_gated||^2 ] + E_{base's own samples of every other
node} [ (1 - r_k) lam(t) ||eps_theta - eps_base||^2 ]` with lam(t) ~ 1/drift_ftfull(t) (upweight low noise, where
C1 measured interference largest: ft-full drift 8.0 at u=0.1 vs 0.24 at u=0.99); dense update, lr 1e-4, no mask;
then `drop_node` and rebuild the affected subtree. This is Prop 2 written as a loss. Trigger = Cobweb accrual:
consolidate node k when `gain_accrued_k = sum_instances (bits_base - bits_gated) >= 8 x bytes(expert_k)` (the 6c-ter
exchange rate: ~15 instances justify 72 B, ~36 justify 1 KB); on this stream it fires after 2-3 concepts for E3 and
never for E1. Kill (2 of 3 seeds): eps-drift on old nodes' samples at u <= 0.3 above 2%, old-class joint drop >
0.02, S1 membership after consolidation < 0.9 x before, or unconditional share of node k outside [0.5, 2] x
count_k/N. If killed, the paper ends at FOLD with experts kept and storage growing with vocabulary; still a result.

**Propositions to add (with the numpy checks that go in `tests/test_propositions.py`).**
- P7 label-free: one instance cannot fix the attach level (for every l >= l_min a node with mode Tweedie(x, u_l) and
  an expert gated below l fits x exactly); two instances sharing the primitive but differing elsewhere identify l* as
  the coarsest level where their per-level modes coincide. Test: planted two-factor mixture; single-instance attach
  likelihood flat across levels within 1e-9; two-instance sym-KL curve has a unique knee at the planted level.
- P8 fold cost tracks depth of novelty d(x) = number of levels at which max_k r_k(x) < 1/2: in the ideal model the
  update over explained levels is <= 2/(n+1) ||x_new - D_n|| and over unexplained levels >= 1/2 ||x_new - D_n||
  near the instance. Test: reuse `posterior` from `tests/test_cobweb_correspondence.py:17`, planted perturbations at
  controlled scale, monotone in d. The network statement (bytes to pass the stop rule grow with d) is Phase 3's
  measurement.
- P9 create vs address: with L(partition) = sum_nodes C_node + sum_i -log2 p(x_i | node(i)), category utility
  (`GaussianCobweb._cu`) and the two-part codelength choose the same operator for N >= N* = C_node / gain per
  instance. Test: a synthetic stream through `GaussianCobweb.ifit` vs `mdl_route_bits` (`router.py:725`); sign
  agreement >= 0.9 for N >= N*, measured N* within 20% of C/gain.
- Composition precondition (Uselis et al. 2026): sibling experts' deltas `delta_k = eps_gated_k - eps_base` must be
  near-orthogonal on the parent's samples (|cos| < 0.2), measured in Phase 4 before two new primitives are composed.

**Differentiation, in one line each.** Tseng: t_b discovered label-free (the level where a node's sym-KL to
siblings floors), a <= 54 KB gated expert not a 7.6 MB duplicated head, branches compose, CONSOLIDATE restructures.
FLLP: our parent is the node whose responsibility explains the coarse levels, the trunk is the model's own score
field, and it merges. Cones/CNS/SMF: flat parameter sparsity drifts on this backbone (C1); E3 is the honest analogue
at matched bytes; SMF gates by activation on the new data alone, ours by responsibility RELATIVE TO SIBLINGS, which
is what bounds interference (Prop 4). MoRAM = E1/E2 with gate G2; ours is analytic and hierarchical. LoraHub/Share =
ADDRESS at 0 new params (LoraHub is the right 0-byte baseline for new combinations). Perfusion: E4's key is the parent
node's read. CURL/CN-DPM: a component only at the levels where the primitive is distinct, then consolidated.

## 4. Benchmark protocol, accounting, metrics, baselines (design 2026-09-25)

Facts that constrain it (verified in code): the ColorMNIST palette is four DARK backgrounds and four BRIGHT foregrounds
(`data/datasets.py:85-91`), so a white background and a red foreground are outside the trained hull while the
withheld bg = 3 (dark brown) is inside it (the shallow-novelty control); the eurecom Shapes3D backbone was

### 4a. Stream rules (all datasets)

- An arrival is ONE real image (THE_TASK's contract). The router reads it label-free; the true tuple is logged only
  to score "stored under the true coordinates". A primitive is folded only after a second arrival shares the
  unexplained residual (create-then-merge, Prop. 7); every new primitive appears in >= 8 arrivals, each in a
  different context on every other factor.
- Population (iv) contexts are factor-disjoint from the fold contexts (fold: digits 0-3 x fg {0,1}; later
  compositions: digits 4-9 x fg {2,3}) so "the expert saw those contexts" is excluded by construction. Two arms:
  read from one image, and coordinates only (node ids, no image). Node ids map to factor values for EVALUATION only
  (40 labelled trained-class images per value decomposed after the tree is built); the router never sees the map.
- Ordering: interleaved (constrained so (iv) follows >= 4 fold arrivals of its primitive) is primary; blocked is
  the forgetting-maximising control on report seeds.
- Seeds 0-2 = development (config, thresholds, expert variant chosen here); seeds 3-5 = report, with different
  permutations, arrival images, held-out cells and both orderings. The frozen config is committed with its hash
  before any seed-3 job; the ledger refuses report rows whose config hash differs.
- Batch-size ladder n in {1, 4, 16, 64} images per fold arrival is a reported CURVE; the headline uses n = 1 and
  reports the arrival count at which absorption was reached. Exception: the phase-3 fold frontier runs the C1
  stream (64 images per concept) so E1 can reproduce 0.716/0.715; its n-ladder is the bridge to n = 1.
- 64 samples per evaluated cell (Wilson half-width 0.115 at p = 0.7 vs 0.19 at C5's 24); replication unit = the
  cell; SE over cells x seeds; probe seed fixed, stream seed varies.

### 4c. Memory accounting: one function, `lifelong_ood/accounting.py::charge(state)`, called after every arrival

Returns total, breakdown, per_arrival, vocabulary_size, stream_len, and the growth exponents alpha (log bytes vs
log V) and beta (log bytes vs log N over the stream tail after the last fold), with bootstrap CIs. Rules: base model
excluded (its size printed once); everything that must exist at test time to regenerate any kept concept is charged,
measured by `numel() * element_size()` or `len(pickle.dumps())`, never by a formula. Codes: an ADDRESS costs
ceil(K_levels x (log2 n_nodes + 16) / 8) B (node id + fp16 weight per level); "72 B" is retired. Node statistics:
level, count, parent, expert id, mode and diagonal extent at the level's stored resolution (fp16); a mode stored as a
regeneration recipe is charged as the recipe ONLY if `tests/test_accounting.py` shows bit-exact regeneration.
Experts: all trainable tensors + keys + scalings. Stored samples of any kind: n x D x element size, uint8 if
reloaded as uint8. Teacher copies and persisted optimizer state: charged in full; forbidden for our method (teacher =
base + frozen experts), and `charge` RAISES on any `state_dict`/`deepcopy` that is not a registered expert; anchor
samples are regenerated per fold (compute, axis 4), not cached. Baselines: EWC Fisher + theta* (54.6 MB on the 6.8M
UNet), C-LoRA usage map, Piggyback 1 bit/param/concept (854 KB), replay's teacher (27.3 MB) or cached samples,
test-time methods charge the query image they need later (3 KB at 32 px, uint8) plus minutes/query on axis 4.
Prediction: ours alpha ~ 1, beta ~ 0; flat LoRA beta ~ 1; C-LoRA / EWC constant but large intercept.

### 4g. Measurement pitfalls designed against

Probe trained on the edit that defines the value (grey wall today): disjoint probe/concept source images, the edit
JITTERED in the probe's training set (saturation 0-0.1, brightness +-10%), readability certified on held-out edited
real images, second judge must agree; same for outline, dim, monochrome. Pixel-space recall retired. Wilson
everywhere; a verdict threshold below `min_detectable` is refused by the report script. Correlated samples: the cell
is the unit. Self-distillation and oracle composition: folds train on the arrival's real images; anchors are the
model's own samples of SIBLING nodes and are charged if kept; every read is from the image with the truth logged
beside it. Wrong rows: `check_split` at the start of every experiment. Stale aggregates: the ledger (Section 6d)
plus `experiments/make_numbers.py` regenerating `paper/numbers.json` from the ledger only, LaTeX `\num{key}` macros,
and a test that no bare decimal appears in prose outside a macro. A reachable `origin` is a deliverable.

### A1. Zekun's method (the ICLR 2027 submission), in the form we inherit it

- Backbones: class-conditional diffusers `UNet2DModel` with CFG dropout (null token), linear beta T=1000,
  eps-prediction, EMA. ColorMNIST 32x32 from `google/ddpm-cifar10-32` config; CelebA 128x128 from
  `google/ddpm-celebahq-256` (sample_size 128). Both checkpoints' bases are in the HF cache on this box
  (`~/.cache/huggingface/hub/models--google--ddpm-cifar10-32`, `...ddpm-celebahq-256`), as is
  `eurecom-ds/scoresdeve-ema-shapes3d-64`. Zekun's own fine-tuned class-conditional checkpoints are NOT on disk;
  the repo has its own ColorMNIST UNet (6.8M params, `nobg3` variant withholds background 3) and Shapes3D VE bridge.
- Prototype = mode of p_t: x_t^(0) = sqrt(abar) x_q + sqrt(1-abar) eps; ascend x <- x + eta s_theta(x,t) with Adam
  (lr 0.01-0.1, 100-200 steps) using the UNCONDITIONAL (null-token) score; Tweedie gives the clean prototype
  m = x*_t / sqrt(abar); extent = diagonal Laplace via 4 Hutchinson probes of the Tweedie Jacobian.
- Hierarchy: symmetric KL between prototypes of different data falls 4 orders of magnitude from fine to coarse
  and floors at t ~ 700-800; a datum's own prototype shows two phase changes (t ~ 100-300 plateau, sharp rise
  300-500 CIFAR / 400-700 CelebA-HQ).
- Composition: timestep grid [50,400,25] (ColorMNIST) / [50,500,50] (CelebA); 128 / 8 ascent starts per level;
  greedy submodular selection of K=3 prototypes by per-dimension coverage F(S)=sum_r max_j l_{j,r}(x_q);
  per-dimension softmax weights (tau 0.5); closed-form Gaussian PoE q_T=N(mu_T, Sigma_T); analytic
  eps_{q_T}(x_t,t) = sqrt(1-abar) Sigma_t^{-1}(x_t - sqrt(abar) mu_T) used as the conditional branch of CFG against
  the null token with variance-aware guidance w*(t)=min(w0 tr(Sigma_t)/d, w_max). DDIM eta=0, 50 steps.
- Benchmarks: ColorMNIST 10 digits x 4 fg x 4 bg = 160 slots, 120 seen / 40 held out (four (fg,bg) pairs held out
  across all digits), 1,000 images per slot. CelebA: 74 realised combinations of 14 binary attributes, 51 seen /
  23 held out (each held-out class differs from a seen class in one attribute), 128x128.
- Metrics: KID (not FID, batch of 16), DPP quality-diversity log det(QSQ)/N with cosine pixel kernel, attribute
  correctness (ColorMNIST: nearest of 160 mean images in pixel space, chance 20%; CelebA: CLIP midpoint rule, 11
  informative attributes). Results: ColorMNIST ours 89.9% / KID 0.10 / div -2.5 vs SDEdit 92.8 / 0.11 / -4.1 vs

### A2. The group's ACS 2026 paper (Wang, Singaravadivelan, MacLellan, "Diffusion Models and Concept Formation")

Four correspondences: tree depth <-> noise level sigma_t; node Gaussian N(mu_c, sigma_c^2 I) <-> mode Gaussian
N(m_c, Sigma_c) with Sigma_c from the Tweedie Jacobian; root-to-leaf categorisation <-> coarse-to-fine denoising;
basic level argmax_c D(c) (distinctiveness = KL(p(x|c) || p(x)), category utility = I(X;C)) <-> maximum-likelihood
mode at noise t*. Measured basic level: Cobweb depth 3, diffusion t* ~ 150 on MNIST and Fashion-MNIST. Their
hierarchy recovery is bottom-up: modes at a fine level grouped within a variance threshold, agglomerated as noise
rises. Stated next step: "how a word comes to pick out a mode of the density, at which level words attach, and
whether that level is the basic level." Stated limitation: the hierarchy is indexed by timestep, not abstraction.

### A3. The Cobweb-update theory already in the repo (`docs/COBWEB_UPDATE.md`, numerically checked)

Prop 1 ideal denoiser = responsibility-weighted mean; Prop 2 adding one instance: D_{n+1} = D_n + r (x_new - D_n),
r = k_new/(K_n + k_new), identical to Cobweb's Welford update with 1/(c+1) -> r; Prop 3 high noise r -> 1/(n+1)
(root), low noise r -> 1 in the new instance's cell (leaf), intermediate r ~ 1/(1+n_eff); Prop 4 interference
bounded by r; Prop 5 first-order weight step = 1/(n+1) natural-gradient step, function change = preconditioned
tangent kernel; Prop 6 best k-sparse support = top-k g^2/F (diagonal Laplace) -- refuted in practice without
anchoring; Prop 7 factor attribution unidentifiable from one concept under additive conditioning. §7: for a local
equivariant denoiser (Kamb & Ganguli) Prop 2 holds PER PATCH -> a Cobweb over parts; untested.

### A8. Cobweb implementation available on disk (verified 2026-09-25)

- Compiled C++ `cobweb` (Teachable-AI-Lab "Very Fast Cobweb") in `~/flash/miniconda3/envs/chunks` (built from
  `/coc/flash10/ksingara3/Chunkformer/cobweb-private`); a newer fork with `cobweb_hybrid` (discrete + continuous,
  `add_only`) at `/coc/flash10/ksingara3/cobweb-llm/cobweb-private`; a numpy `GaussianCobweb` in
  `lifelong_ood/tree.py` (correct expected-correct-guesses CU, `:58-76`); `lifelong_ood/backend.py` picks C++ when it
  imports (`covar_from=1`, `alpha=1e-6`).
- Continuous node = (count, mean, sum_sq, label_counts); Welford update `n+=1; d=x-mu; mu+=d/n; sum_sq+=d*(x-mu_new)`;
  merge `sum_sq = S_a + S_b + (mu_b-mu_a)^2 n_a n_b/(n_a+n_b)`; variance = sum_sq/count + prior_var (the acuity).
- Operators (`cobweb_continuous_tree.cpp::cobweb`): BEST (update, descend), NEW (singleton child N(x, prior_var),
  weight 1/(n+1)), MERGE (pool the two best children under a new node), SPLIT (promote a child's children); chosen
  by max partition utility PU = (1/K) sum_k P(C_k) score_k with score = 0.5 sum_d [log v_parent - log v_child]
  (the Gaussian entropy drop = information-theoretic CU, Corter & Gluck 1992). Fringe split at a leaf.
- Categorise: `get_leaf` by argmax log p(x|c) + log(n_c/n_root); `categorize_with_stopping` stops where
  pu_new >= pu_best; `predict` mixes best-first expanded nodes; `get_basic` = node of max closed-form expected PMI
  along the path (the ACS paper's distinctiveness). `ifit` touches one root-to-leaf path with sufficient statistics
  only; order-dependent (seeds = presentation orders).
- Deep Taxonomic Networks (NeurIPS 2025): a VAE whose prior is a complete binary tree of Gaussians with
  moment-matched parents; ELBO ~ I(Z;T) - I(Z;X) + G so maximising it maximises CU; leaves + alpha weights learned.
- cobweb-poincare B10 negatives that motivate FOLD: a per-dimension PoE can only INTERPOLATE (each pixel stays inside
  its experts' range: a colour no expert has cannot be produced; all3 saturates < 0.4 at R^2 0.944); absorbing new
  images by `ifit` into a tree with a frozen decoder changes OOD R^2 by less than the seed swing; the PoE sampler
  redecorates the query (0.1% of samples "far"). Zekun's Appendix J (white background fails) is the same limit
  seen from the diffusion side.
- Zekun's v1 (poe-diffusion.pdf) had an optional LoRA distillation: a new class embedding + rank-8/16 LoRA trained on
  256 PoE samples lifted ColorMNIST F1 75.3/63.0 -> 87.6/76.3. That is self-distillation from an interpolating
  teacher (the audit's fault #2), not folding real evidence.
- `lifelong_ood/compose.py` deviates from the paper: adaptive temperature, a "mixture" extent (product covariance
  sigma 0.019 vs the real class's 0.120), a 20x smaller ascent budget by default (`candidates_ascent :102-155`).

### A9. Verified details of the two closest prior works (fetched full texts)

- Tseng, Shen, Biancalani, Scalia, "Hierarchically branched diffusion models leverage dataset structure for
  class-conditional generation" (2212.10777v4, Feb 2024, no venue): branch point = "the earliest diffusion time at
  which the average similarity between noisy objects of different classes is comparable to the average similarity
  between noisy objects of the same class"; a novel class is added by "training only on c' for times t in [0, t_b]"
  with shared parameters frozen; 2|C|-1 branches as heads of one multi-task network; continual experiments on
  MNIST (0,4,9 -> add 7) and scRNA-seq scored by FID; "transmutation" = analogy generation across a branch point.
- FLLP (AAAI-26, 2601.01892): per concept stores LoRA weights, token embedding(s) and a "timestep-weighted mean
  representation" of attention maps; parents found automatically by Lorentzian geodesic distance over CLIP image
  features and token embeddings (ParentSearch); hierarchy static after insertion; multi-concept generation by
  Elastic Weight Aggregation of LoRAs; CIFC/CelebA/ImageNet at 10 concepts (+2.0/+1.3, +4.4/+2.0, +1.1/+0.5
  IA/TA over C-LoRA), CustomConcept101 to 35 concepts.
